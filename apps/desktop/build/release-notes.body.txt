BeatBax Desktop vX.Y.Z — Per-category CodeLens previews, more reliable
  Copilot edits, and clearer DMC sample warnings.

  Features
  - Per-category CodeLens previews: Settings → Editor keeps the
    Show CodeLens previews master toggle and adds sub-toggles for pattern,
    sequence, instrument and effect previews. All default to on, so existing
    setups are unchanged.

  Copilot
  - Edit results now match what reaches the editor, especially with local
    models. CRLF songs no longer show every line as changed, and replies that
    leave definitions out are merged instead of having references removed.
  - Changes Copilot cannot merge (such as the `play` line) are listed in a
    Not merged note, and any Edit turn that leaves the song unchanged shows a
    Not applied badge with the reason.
  - Follow-up edits such as "do the same for the bass" work without resending
    earlier Edit turns, which small models tended to copy.
  - The edit card warns when only comments changed, or when the explanation
    names patterns or sequences that were not changed.
  - Context meter: Start a new chat is now a button, shown when chat history
    fills the window; a fresh chat that is already near the limit offers
    Open AI settings instead.
  - Settings → AI → Advanced adds Edit and Ask reply budgets and Reasoning
    effort. On Auto, the reply budget fits the room left in the model token
    window, and the context meter reserves exactly what is sent.
  - When a reply runs out of budget, Copilot says why (for example, the
    model spent it on reasoning) and which setting to change, instead of
    "try again". Large songs that cannot fit get a warning before sending.
  - Rejected request parameters are remembered for the session, so later
    requests to the same model are sent once.
  - Edits stay closer to the request: existing sequence entries are kept,
    copied patterns keep their length, and "each" applies to every phrase.

  Diagnostics
  - Warnings and errors are written to a log file you can attach to bug
    reports: Help → Open Logs Folder. Song text, Copilot prompts and API keys
    are never logged.
  - Developer tools are off by default. Turn them on in Settings → Advanced →
    Enable developer tools, or for one session with the --devtools launch
    flag. On macOS, View → Toggle Developer Tools now only appears when they
    are enabled.
  - The startup error screen has Open logs folder and (when allowed) Open
    developer tools buttons, instead of pointing at a menu that may not exist.

  Fixes
  - NES DMC sample-load warnings now appear in the Output panel, once per
    play. Remote asset errors are easier to read, and a blocked host points to
    Settings → Advanced → Remote host allowlist.

  Note: Windows installers are still not Authenticode-signed; SmartScreen may
  warn — use More info, then Run anyway (see README.txt). Verify downloads with
  SHA256SUMS (and GPG when published).
