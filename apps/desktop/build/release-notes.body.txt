BeatBax Desktop v0.3.0 — Instrument Editor, Pattern Grid section focus,
  Copilot sessions, and more reliable imports/exports.

  Features
  - Instrument Editor panel (Experimental, default off): chip-aware fields,
    waveform drawing, macro graphs, templates, and preview from a
    mini piano or a connected MIDI keyboard. Edits write back into the open
    `.bax` `inst` lines.
  - Pattern Grid section focus: play one arrangement slice across all channels
    (F6 enter; Esc exit; Alt+Left/Right previous/next section; F5/F8 scoped
    to the focused section).
  - Channel Mixer defaults to inline mode so the right pane keeps full height;
    switch to full-window width when you need more channel strips. Right-pane
    tabs get icons and a compact layout.
  - External `.bax` file watcher: reload when another editor changes the open
    file (Settings → Editor: When the open file changes on disk).
  - Command palette and feature-context cleanup so desktop commands stay
    easier to find.

  Chip and export improvements
  - Desktop export merges imported instrument kits before writing (issue #171),
    so JSON/MIDI/UGE/WAV include instruments from `import` files.
  - Native `subpat` declarations in `.ins` imports; CodeLens preview of
    imported instruments; named effects can be imported.
  - UGE export reuses and optimizes patterns for smaller tracker output.

  Copilot and editor
  - Copilot sessions (multiple chats), a context-usage meter, and per-change
    edit review before applying suggestions.

  Installers, signing and examples
  - macOS GitHub Release .dmg/.zip are Developer ID signed and notarized.
  - Release checksums: SHA256SUMS; optional GPG (SHA256SUMS.asc,
    beatbax-release.asc) and dpkg-sig for .deb.

  Fixes
  - Import/export and CodeLens preview gaps for kit instruments and named
    effects.
  - Pattern Grid section playback and Channel Mixer layout polish.

  Note: Windows installers are still not Authenticode-signed; SmartScreen may
  warn — use More info, then Run anyway (see README.txt). Verify downloads with
  SHA256SUMS (and GPG when published).
